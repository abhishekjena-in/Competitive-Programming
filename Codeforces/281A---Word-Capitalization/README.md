# [281A---Word-Capitalization](https://codeforces.com/problemset/problem/281/A)

> **Platform:** `Codeforces` | **Time Limit:** `2 seconds` | **Memory Limit:** `256 megabytes`  
> **Direct Link:** [Open Problem Statement](https://codeforces.com/problemset/problem/281/A)

---

### 📖 Problem Statement
Capitalization is writing a word with its first letter as a capital letter. Your task is to capitalize the given word.

Note, that during capitalization all the letters except the first one remains unchanged.

---

### 📥 Input Specification
A single line contains a non-empty word. This word consists of lowercase and uppercase English letters. The length of the word will not exceed  *103* .

---

### 📤 Output Specification
Output the given word after capitalization.

---

### 🧪 Sample Tests

#### Example 1
**Input:**
```text
ApPLe
```

**Output:**
```text
ApPLe
```


#### Example 2
**Input:**
```text
konjac
```

**Output:**
```text
Konjac
```
